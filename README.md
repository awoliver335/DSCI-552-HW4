# DSCI 552 - Homework 4

Activity classification on the AReM dataset using logistic regression and naive Bayes.

The required work is in [Oliver_Austin_HW4.ipynb](Oliver_Austin_HW4.ipynb). Optional exercises are in [Oliver_Austin_HW4_Extra_Practice.ipynb](Oliver_Austin_HW4_Extra_Practice.ipynb).

The HW4 notebook loads [Oliver_Austin_HW3.ipynb](Oliver_Austin_HW3.ipynb) to reuse its data cleaning, train/test split, and feature extraction. Keep both notebooks in the repository root; running all HW4 cells automatically executes HW3 with its output captured. The HW3 notebooks remain in the repo, with data in `data/` and instructions in `homework_assignments/`.

Install the packages below, then open the HW4 notebook in Jupyter or VS Code and run all cells from the repo folder.

```bash
pip install numpy pandas scipy matplotlib seaborn scikit-learn==1.7.2 ipykernel
```
